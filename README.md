# CriptoCoins
Aplicação desenvolvida em React que permite acompanhar e consultar informações de diferentes criptomoedas utilizando a API da CoinCap.

O projeto apresenta uma listagem de moedas digitais com informações como nome, símbolo, posição no ranking, preço de mercado, capitalização e outras métricas relevantes.

O objetivo é oferecer uma interface simples, intuitiva e dinâmica para visualizar dados do mercado de criptomoedas, consumindo informações atualizadas diretamente da API da CoinCap.
